# PHASE DECLARATION CRITERIA

Phases are not motivational labels.  
They are retrospective architectural confirmations.

---

## Criteria

1. Structural shift confirmed  
2. Snapshot evidence present  
3. Repeatability demonstrated  
4. Previous phase completed  
5. Risk assessed  
6. Retrospective framing only  

---

## Required Artifacts

- phase closeout summary  
- updated phase index  
- updated temporal index (`EPOCH_INDEX.md`)  
- documented structural shift  

---

## Governance Standard

If criteria are partially met, the system remains in the current phase.

Conservatism protects integrity.
