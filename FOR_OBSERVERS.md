# For observers

This repository is not a product, guide, or framework.  
It is a working system.

---

## What you're looking at

A longitudinal self-tracking system built around three separations:

- **raw data** (snapshots)  
- **interpretation** (reports)  
- **presentation** (dashboards)  

Each layer is intentionally isolated.

---

## Constraints

- Snapshots are immutable  
- Reports are structured interpretations of past data  
- Dashboards are derived views only  

```
[ SYSTEM RULES ]

- No forward claims
- Only retrospective validation
```

---

## Why this exists

Most self-tracking systems collapse these layers.

When that happens, data becomes narrative.

This system is designed to prevent that.

---
