# STRUCTURAL PRINCIPLES

This document codifies how decisions are made within the Daniel Longitudinal system.

It exists to prevent drift, novelty-chasing, and narrative bias.

All structural changes must align with these principles.

---

# 1. Artifact Supremacy

No strategic decision is made without reference to:

- Confirmed snapshot measurements
- Logged training artifacts
- Verified biomarker data

Speculation does not override artifacts.

---

# 2. Signal Over Volume

Training adjustments prioritize:

- Adaptation signal density
- Recovery integrity
- Structural durability

Volume increases must be justified by recovery metrics and prior adaptation success.

---

# 3. Bias Awareness

Each phase has a dominant stimulus bias.

Before introducing change, the following must be identified:

- Current dominant bias
- Current limiting factor
- Risk of overcorrection

Shifts must be architectural, not reactive.

---

# 4. Reversibility Test

All new structural elements must pass the reversibility test:

- Can this be scaled down safely?
- Can this be removed without systemic collapse?
- Does this introduce unnecessary dependency?

If not reversible, it must be reconsidered.

---

# 5. Snapshot Confirmation

Claims of progress require:

- DEXA / Bod Pod confirmation
- Bloodwork normalization
- Repeatable performance markers

No phase advancement is declared without objective confirmation.

---

# 6. Constraint Identification

Before increasing load, identify:

- Current weakest system
- Recovery bottleneck
- Mechanical limitation
- Hormonal stress signal

The system is optimized by strengthening constraints, not amplifying strengths.

---

# 7. Public Integrity

The public repository:

- Does not exaggerate
- Does not predict
- Does not posture
- Does not introduce unverified claims

It reflects only confirmed structure.

---

# 8. Architectural Stability Over Novelty

Innovation is introduced only when:

- The current structure is stable
- Metrics are consistent
- Recovery markers are strong

Stability precedes expansion.

---

# Governing Principle

If a change improves short-term performance but increases long-term instability, it is rejected.

The system favors durability over speed.
