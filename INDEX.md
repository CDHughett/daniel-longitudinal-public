# Daniel Longitudinal Study — Index

This repository is a structured public archive of an ongoing longitudinal self-observation system focused on biological optimization, performance capacity, recovery behavior, and protocol evolution under controlled constraints.

**This is not a coaching product.**  
**This is not a fitness journal.**  
**This is a governed, versioned archive.**
