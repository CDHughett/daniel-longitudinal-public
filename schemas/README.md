# Schemas

This directory contains archive-defined templates and structural contracts.

## Current schema surfaces

- [`machine-readable-layer-v1.md`](./machine-readable-layer-v1.md) — schema contract for `daily_biomarkers_v1.csv`, `training_blocks_v1.csv`, and `context_events_v1.csv`
- [`weekly-report-template.md`](./weekly-report-template.md) — recurring weekly-report structure
- [`experiment-template.md`](./experiment-template.md) — experiment-record template
- [`metrics-dictionary.md`](./metrics-dictionary.md) — reserved cross-domain metrics dictionary

Global field definitions and measurement conventions remain documented in:

- [`../DATA_DICTIONARY.md`](../DATA_DICTIONARY.md)

Schema files define structure.

They do not authorize source correction, imputation, biological interpretation, or retrospective rewriting.
