# Hypothesis Note — Population Baseline Misfit

## Internal Working Idea

One possible interpretation of repeated directional model
error is that general population baselines may be a poor
reference class for this subject under sustained
high-compliance, low-interference conditions.

## Current Status

This is not treated as a conclusion.

It is treated as a testable interpretation that may be
supported or weakened by:
- directional pre-calibration error
- reduced post-calibration error
- residual positive UDI after calibration
- persistence across domains

## Public Handling

Until the dataset is denser, this idea should be expressed
publicly only as a working hypothesis under measurement.
