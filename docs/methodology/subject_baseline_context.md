# Subject Baseline Context

This document defines known **pre-observation conditions** present at the start of the longitudinal archive.

It exists to establish **context boundaries**, not to provide interpretation.

This file does not assign causality, predict outcomes, or evaluate biological response.

---

## Purpose

This document provides a factual record of known subject history at the time the observation system begins.

It ensures that:

- baseline conditions are explicitly documented
- longitudinal changes are not interpreted without reference to prior state
- future readers have a stable context for interpreting divergence between datasets

---

## Pre-Observation Conditions

At the start of Phase 0, the subject had a documented history of:

- heavy tobacco use (cigarettes, vapes)
- chronic alcohol use
- chronic THC use post service
- chronic caffeine use
- sustained ultra-processed food consumption

These conditions were present across significant portions of adult life.

---

## Medication State

Prior to Phase 0:

- subject was prescribed and using multiple pharmaceutical compounds

At the start of Phase 0:

- all medications were discontinued

This represents a **major environmental and physiological change** in the observation system.

---

## Interpretation Boundary

The presence of prior exposure history introduces **known structural constraints** on interpretation.

This includes, but is not limited to:

- differences between short-horizon biological pace metrics and longer-horizon tissue state metrics
- persistence of historical exposure signals in biomarker outputs
- lag between behavioral change and observable system-level normalization

This document does not assign meaning to these conditions.

It defines that:

> **observed values must be interpreted with awareness of prior state, but not explained by it without sufficient artifact evidence**

---

## Known Baseline Conditions

The following observed measurements are treated as **baseline conditions at time of capture**:

- PFOS at high percentile relative to reference population
- vascular-related markers (including SDMA/ADMA, phenylacetylglutamine) outside optimal ranges

These are recorded as:

- **known present conditions**
- **not actively modeled as intervention targets within this layer**

---

## Scope

This document:

- defines prior conditions
- establishes interpretation constraints
- supports longitudinal context

This document does **not**:

- interpret biomarker meaning
- define causal relationships
- predict convergence timelines
- override artifact-based observation

---

This file is part of the **methodology layer**.

- snapshot artifacts
