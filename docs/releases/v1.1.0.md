## Why v1.1.0

Version 1.1.0 represents a meaningful compatible archive milestone rather than a routine weekly rollover. Since v1.0.0, the repository has added a completed August 2026 coordinated biological/performance snapshot, materially expanded machine-readable longitudinal coverage, closed the recent protected prediction block, strengthened provenance and validation, and completed independent post-snapshot and release-readiness audits.

No breaking dataset schema, evidence hierarchy, prediction framework, or phase-governance rule is introduced. The release is therefore classified as a minor rather than major version.

## Record 043 supplemental cleanup

The current canonical Record 043 closure distinguishes the state at adjudication from the later source-backed completion of August Bod Pod fields.

At adjudication, Bod Pod was supplemental and not required for scoring. The later post-snapshot cleanup directly transcribed the retained COSMED values into the integrated snapshot. This improved archive completeness without altering:

- original prediction wording
- registered thresholds
- core-anchor classifications
- supporting-profile arithmetic
- actual outcome
- support status

The original adjudication-era closure text remains preserved in the model-error archive.

## Known limitations carried into v1.1.0

The release intentionally preserves bounded unresolved or restricted data-quality issues rather than substituting plausible values. Material examples include:

- DQ-001 — historical awake-minute / awakening-count duplication interval
- DQ-002 — 2026-03-31 sleep-stage reconciliation
- DQ-003 — 2026-04-02 sleep-stage reconciliation
- DQ-011 — source verification of the recorded 2026-09-08 daily resting-heart-rate value of 64 bpm

Some historical private `Daniel_Dataset` source versions also lack exact immutable retained files for SHA-256 registration. Those hashes remain explicitly unavailable rather than reconstructed.

These are disclosed field- or provenance-level limitations. They do not imply that every field in the affected rows, or the archive as a whole, is invalid.

## Scope boundary

This repository is a governed single-subject longitudinal observational archive. It does not establish:

- population-level causality
- clinical efficacy
- generalized intervention guidance
- protocol safety for other people
- universal device or assay accuracy

The release milestone does not declare a new physiological phase. Current state remains:

```text
Phase 2 — Load Integration
Operating substate: Consolidation / re-entry observation
Installed architecture: B1 + Load Integration
Phase 2D: undeclared
```
