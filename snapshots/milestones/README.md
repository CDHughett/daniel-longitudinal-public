# Milestone Artifacts

This directory contains symbolic artifacts associated with the historical progression of the Daniel Longitudinal Study.

Milestone artifacts may include:

- challenge coins
- recognition tokens
- symbolic markers associated with notable events in the archive timeline

These artifacts document **external observation or contextual recognition** of developments occurring within the longitudinal system.

Milestone artifacts do **not represent primary biological measurements**.

Primary measurement artifacts are stored in:

/snapshots

---

## Archive Principle

Measurements provide evidence.  
Reports provide interpretation.  
Milestones provide historical context.
