### Blood-Artifact Sanitization Status

The current public version of:

`2025-07-full-blood-panel.pdf`

is a sanitized derivative created to reduce unnecessary administrative exposure while preserving the biological evidence.

The public derivative removes:

- full date of birth
- patient identifier
- specimen identifier
- street address
- private contact information
- ordering-physician identity

The public derivative preserves:

- analyte names
- measured values
- units
- reference intervals
- abnormality flags
- collection and report context
- laboratory identity
- interpretation-relevant comments
- page order and result associations

The replacement is classified as:

- privacy remediation
- archive maintenance
- source-preserving public sanitization
- checksum-changing artifact replacement
- not new biological evidence
- not a correction to the measured laboratory values
- not a protocol or phase event

The sanitized derivative should not be interpreted as an untouched provider original.

### Public and Private Source Boundary

The public repository contains the sanitized derivative rather than the complete administrative provider document.

- public evidentiary value

- transparency regarding artifact transformation

That limitation is intentional and should remain visible.
